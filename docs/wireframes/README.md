# Wireframes

One image per screen, drawn before the spec and before any code. Hand sketches (photographed), Excalidraw or Figma exports are all fine.

## Naming

`S<nn>-<short-name>.png`, matching the screen ID in [../screen-specs/README.md](../screen-specs/README.md). Profile variants of the same screen add a suffix:

- `S07-forecast-card-do.png` for "Just tell me what to do"
- `S07-forecast-card-why.png` for "Show me why"
- `S07-forecast-card-sure.png` for "How sure, and what changed?"

Keep the source file (`.excalidraw`, Figma link in the spec) so the wireframe can be edited later.

## What a wireframe must show

- Every element in order, with its real text, not lorem ipsum
- Which buttons go where (Why?, How sure?, Ask someone to explain)
- The "Synthetic data" label on forecast screens
- Where each of the five invariants sits (hazard, place, time window, likelihood, action)

Wireframes freeze on 22 Oct (plan checkpoint).
