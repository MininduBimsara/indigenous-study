# Screen specs

One spec per screen, written from that screen's wireframe and before any code. Copy [`_template.md`](_template.md) to `S<nn>-<short-name>.md`.

A spec is what the AI prompt (see [../ai-prompting-template.md](../ai-prompting-template.md)) and the reviewer both work from, so it lists the exact text, the components and which profile attribute each part reads.
